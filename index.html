Selected Projects

Selected machine learning projects across language models, multimodal learning, representation learning, interpretable AI, and computer vision.

NLP · Language Models 01

Patent Intelligence & Language Models

Developed machine learning approaches for predicting patent approval time from patent text and structured metadata. Investigated domain-specific transformer representations using PatentBERT and compared them with LLMs and TF-IDF-based neural models.

PatentBERT LLMs Transformers NLP TF-IDF Neural Networks Structured Data
Deep Learning . Unsupervised Learning 02

PROTECT

Developed an unsupervised deep learning framework for estimating circadian phase directly from high-dimensional proteomic data.

The model combines unsupervised pretraining with a custom cosine-based loss for circadian phase estimation, enabling it to learn temporal structure from high-dimensional proteomic data without time labels.

Deep Learning · Unsupervised Learning 03

Learning Biological Time from Gene Expression

Developed unsupervised learning model for estimating circadian phase and rhythmic structure from high-dimensional transcriptomic data.

This research includes the PENN framework and investigates how machine learning can recover latent temporal information from biological measurements.

Multimodal AI · Computer Vision 04

Multimodal Deep Learning for Edema Classification

Developed a multimodal deep learning framework combining head CT imaging with structured clinical information for edema classification.

The work investigated how information from heterogeneous modalities can be combined within a unified learning framework for medical image classification.

Interpretable AI · Symbolic ML 05

Interpretable AI for Disease Identification

Developed interpretable machine learning models using Kolmogorov-Arnold Networks (KANs) that reduce high-dimensional gene-expression profiles to compact diagnostic signatures.

This work includes two-gene symbolic diagnostic formulas evaluated using independent bulk and single-cell RNA datasets across multiple cancer types, as well as compact gene-expression classifiers for cancer detection.
